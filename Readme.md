Esse é o repositório Mobile do projeto PlanLine. Ele é responsável por prover a aplicação mobile do projeto.

## EXPO

Expo é um framework para desenvolvimento para aplicação Mobile. Ele fornece ferramentas e bibliotecas de uso mais simplificadas para o desenvolvimento do mobile.

## Desenvolvimento

1. Instale o [Node.js](https://nodejs.org/en) versão `>= 18`.

2. Instale o [Yarn](https://yarnpkg.com/) com o comando:

```sh
npm install -g yarn
```

3. Instale as dependências do projeto com o comando:

```sh
yarn install
```

Para isso, é necessário estar com um terminal aberto na pasta raiz do projeto.

4. Instale a aplicação do Expo em seu celular, utilizando a loja do Android ou iOS.

5. Para iniciar o servidor de desenvolvimento, execute o comando:

```sh
yarn start
```

A aplicação irá gerar um QR Code que deve ser lido pela aplicação Expo do seu celular.

Tanto o seu celular quanto o projeto devem estar na mesma rede para funcionar

6. Para mais comandos, veja o arquivo `package.json` na raiz do projeto.
