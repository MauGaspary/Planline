Esse é o repositório Mobile do projeto PlanLine. Ele é responsável por prover a aplicação mobile do projeto.

## 💻 Desenvolvimento

![NodeJS](https://img.shields.io/badge/node.js-6DA55F?style=for-the-badge&logo=node.js&logoColor=white)
![Yarn](https://img.shields.io/badge/yarn-%232C8EBB.svg?style=for-the-badge&logo=yarn&logoColor=white)

1. Instale o [Node.js](https://nodejs.org/en) versão `>= 18`.

2. Instale o [Yarn](https://yarnpkg.com/) com o comando:

```sh
npm install -g yarn
```

É necessário estar com o terminal aberto na pasta raiz do projeto.

3. Instale as dependências do projeto com o comando:

```sh
yarn install
```

4. Para iniciar o servidor de desenvolvimento, execute o comando:

```sh
yarn start
```

5. Instale o app do Expo em seu celular, utilizando a loja do Android ou iOS.

Tanto o seu celular, quanto o projeto, devem estar na **mesma rede** para funcionar.

6. A aplicação irá gerar um QR Code no terminal, que deve ser lido no app do Expo em seu celular.

Para mais comandos, veja o arquivo `package.json` na raiz do projeto.
